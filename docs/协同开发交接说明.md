## 需求与开发预期

StudyPilot 是业务系统；DeepSeek Harness 是独立、可替换的 Agent Runtime。业务专精通过 profile、context、tools、control 插件进入，不重写原 loop、工具调度、模型流、上下文压缩与恢复，不让旧固定 Planner 包住新 Runtime。

Java 提供可信身份、业务事实、权限、预算、确认、幂等与审计；Agent Service 拥有 Runtime、会话、模型配置及 Secret；Vue 通过同源 Agent API 接入。API Key 和模型地址不进入 Java 业务配置，Secret 不进入浏览器持久存储或事件日志。Harness 不直连业务数据库，不把开发终端能力开放给最终产品 Agent。

产品交互为全局悬浮球：左键打开 Harness 风格窗口，右键提供设置、新会话、历史及状态。保留自然判断、补查、追问与工具结果后的继续推理，避免关键词脚本或固定答复代替模型判断。旧 Agent 专属页面在新路径验收后迁移，保留业务页与历史数据。

原能力不被业务代码破坏是机制约束与评测目标，不能承诺任意回答完全相同。完整 Capability Manifest 基于真实接口编译；页面上下文仅提供定位提示，不能授予权限。先离线基线，H05 治理后才做真实 DeepSeek 成对评测。

设计：[接入设计](superpowers/specs/2026-10-08-studypilot-harness-integration-design.md)。执行：[H01～H12 计划](superpowers/plans/2026-10-08-studypilot-pluggable-harness-runtime.md)。历史：[旧交接全文](history/2026-10-08-协同开发交接说明-旧版.md)，仅供溯源，旧 push/merge/下一 Task 指令不自动生效。
